基于Python的双均线量化交易回测系统
项目简介
本项目基于 Python 构建了一套轻量级的 A 股量化回测框架，以平安银行（000001）为例，验证了经典的双均线（MA5/MA20）策略在历史行情中的实际表现。
项目涵盖了数据获取、清洗、策略信号生成、模拟交易、绩效评估以及可视化展示的完整生命周期，并与“买入持有（Buy & Hold）”基准策略进行了详细的收益与风险对比。
技术栈
数据获取：Akshare
数据处理：Pandas, NumPy (时间序列对齐、指标计算、收益回测)
可视化展示：Plotly (交互式K线、买卖点标记、累计净值对比图)
